# UCL logo

`ucl-logo.png` is the unmodified white portico-and-lettering PNG from
[UCL's Indigo design repository](https://github.com/UCL-WAMS/indigo/blob/develop/images/ucl-logo-cropped-white.png),
downloaded on 19 October 2026. `UclLogo` displays it on black to match the
[logo reference supplied by the user](https://www.cleanpng.com/png-ucl-logo-with-capitol-building-icon-wlzn45/).
The CleanPNG watermarked preview is not bundled. The image is served locally;
the frontend makes no runtime request to either source.
